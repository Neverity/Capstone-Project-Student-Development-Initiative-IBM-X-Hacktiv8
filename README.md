# Project Title
Personal Portfolio Website – Fathan Andhika Daffa Putra Adhiwibowo

# Description
Personal Portfolio Website ini merupakan proyek capstone dalam program Student Developer Initiative (Hacktiv8 x IBM).
Tujuan website ini adalah menampilkan profil pribadi, keahlian, serta proyek yang pernah dibuat dalam format landing page yang sederhana dan responsif.

Proyek ini dikembangkan dengan bantuan AI IBM Granite untuk mempercepat proses penulisan kode, mengoptimalkan struktur HTML dan CSS, serta menghasilkan dokumentasi yang lebih efisien.

# Technologies Used
HTML5 – Struktur halaman web.  
CSS3 – Styling dan layout responsif.  
JavaScript (Vanilla) – Interaksi sederhana seperti tombol scroll dan animasi kecil.  
Google Gemini – Membantu generate kode, dokumentasi, dan optimasi desain.  
Netlify – Deployment website secara gratis dan cepat.  

# Features
About Me Section – Menampilkan profil singkat dan keahlian.  
Projects Section – Showcase proyek yang pernah dibuat.  
Contact Section – Form kontak sederhana menggunakan Google Form.  
Responsive Design – Tampil baik di layar desktop maupun mobile.  
Smooth Navigation – Navigasi sederhana dan intuitif.
